# DR2 領域配分の実装・検証（2026-11-15）

対象: main `0948f48`を基点とする`feat/dr2-workspace-layout`の変更。ユーザーの「進めて」により[改訂モック・計画](../design/dr2-layout-plan.md)を承認後に実装。実装後にコミット・PR作成の指示を受領。マージは未実施。

## 実装内容

- **D01:** Meeting Liveは右欄の先頭に提案・回答を表示し、質問欄とAI停止操作を結果スクロールから分離。AI設定と資料をシートから開く。狭幅は提案→会話、根拠リンクで会話へ移動する。準備・ライブ間で質問下書きを保持する。
- **D09:** Conferenceの保存を上部の書き出し横へ移動。取得中／空／保存済みの無効化、変更後の再保存、保存エラーの詳細と再試行を維持。狭幅では上部バー内で折り返す。
- **D02:** シェルのサイドバーは1024ptから、字幕2列は字幕領域820ptから。支援欄はコンテンツ1161pt（現行シェルで1346pt）以上で自動表示。それ以下では字幕幅を削らず重ねて開く。全幅で開閉でき、Escapeで閉じて起点へフォーカスを戻す。
- Conferenceの支援回答も設定より先に表示。支援欄と資料シートの質問は同じ下書きを参照する。開閉・リサイズで回答、下書き、会議IDを保持する。
- `MeetingPaneLayout`で同じビューを再配置し、ライブ→振り返りでもスクロールを維持。既存`RevealOnFocus`を使い、低い画面ではフォーカスした質問・操作を見える位置へ移す。
- 保存形式・音声取得・AI要求／許可の契約は変更していない。実音声・実APIは使用していない。
