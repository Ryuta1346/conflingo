## 実装した動作

- 決定／アクション候補は未確認で取り込み、利用者の操作で確認済み／却下／未確認へ変更する。生成中・中断、根拠なし・無効根拠の確定は不可。最新100件のAIカードの表示上限とは独立して候補を保持する。
- 終了後の要約は送信対象全文・言語・区間数／予定要求数を確認して開始。30発話／12,000文字で区切り、最大20区間、直列実行、自動再送なし。対象を黙って切り捨てない。全文を統合した1つの要約ではなく、根拠付き区間別要約を提供する。
- 未完了・失敗・取消を完成扱いせず、再生成が失敗しても以前の完成版を保持する。要約停止、共通AI停止、キー変更、画面移動、会議破棄で取消し、遅延応答を採用しない。会議終了後に音声や会議中AIを再開しない。
- Markdownは会議情報、完成したAI要約（未確認）、確認済み／未確認／却下の候補、根拠リンク、確定発話を含む。AI一般回答やpartialは混入させない。キャンセル／失敗で会議を保持し、成功時だけ出力完了を表示。内容変更後は以前の出力との相違を表示する。
- アプリ内Sessionsの保存一覧・再読込・削除、候補編集、担当／期限入力、RAGは後続。ConferenceのMarkdown形式は変更していない。
