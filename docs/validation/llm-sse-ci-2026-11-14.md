# LLM分岐・SSE集約とCIの検証

2026-11-14。基点: main `50f59d4`（PR #42マージ済み）。[計画](../design/llm-sse-ci-plan.md)。ローカル実装・自動検証完了。未コミット・未PR。独立レビューとリモートCI実行は未実施。

## 変更

- `LLMInsightRequest`と`LLMResearchRequest`へ各社の要求生成を分離。`LLMHTTPRequest`がJSON化、要求128 KiB上限、Content-Type/Accept、認証を共用する。schema、検索tool、store=false、thinking設定、モデル・タイムアウトは維持。
- `LLMInsightClient`に全providerの送受信ループを集約。Gemini専用入口もここへ委譲し、キー取得は一回。取消後に届くGeminiのchunkがプレビューへ出る問題も修正。
- `SSEFramer`へUTF-8行復元・CRLF・data行結合・EOF処理・受信上限を集約。総受信2 MiB、行/イベント64 KiB、本文64 KiBを維持。逐次処理し、イベントの配列をため込まない。
- `LLMStreamDecoder`がGemini/OpenAI/Claude/Chat用イベント解釈を選択。GeminiのSTOP後usageと[DONE]、他社の終端/拒否/usage契約は各型が保持。旧Gemini専用フレーミングを削除。
- macOS 26 arm64・Xcode 26.6・SwiftLint 0.65.1の[CI](ci.md)を追加。read-only権限、固定Action SHA、SwiftLint配布物の固定SHA-256、30分上限、同一ref取消、ログ/xcresultの7日保持を設定。README英日構成図・実行案内を更新。
