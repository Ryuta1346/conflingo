## 検索仕様

OS同梱SQLite 3.51.0のFTS5をインメモリで利用。NaturalLanguageの単語分割を索引／検索語双方に適用し、SQLパラメータと引用済み検索語で検索する。標準unicode61は連続した文字を1トークンとするため、日本語をそのまま投入する方式は使わない。[SQLite FTS5公式仕様](https://www.sqlite.org/fts5.html#unicode61_tokenizer)。

一般的な助詞・質問語を除き、最大32語のOR検索をrank順で最大10件返す。日英の単語検索であり、任意の部分文字列・意味検索・同義語展開ではない。長い行は最大1,200文字で分割するため、境界をまたぐ語が一致しない場合がある。BOMを除去し改行をLFに揃えた取り込み本文に対して、行・文字位置を保持する。

## 非録音のネイティブUI

CUAで専用コピー`/private/tmp/conflingo-pr8-ui/ConfLingoPR8.app`（bundle ID `com.gavrri.conflingo.pr8-validation`）を`--meeting-preview --meeting-state=pr8-setup`で操作。PreviewInsightClient・PreviewAudioSource使用、実APIフラグなし。

確認済み:

1. AI送信オフで「料金」を検索し、文書名・位置・取り込み日時・抜粋を表示。Escで閉じる。
2. OSファイル選択で一時的な合成Textを取り込み、資料数が1→2になり文字数を表示。選択キャンセルでは変更なし。
3. 合成会議で発話／質問許可と資料許可をオンにし、質問入力→TabでAsk AIへ→Spaceで送信。資料1箇所の参照と架空の回答・引用リンクを表示。
4. 小窓から引用をクリックし、主画面の引用シートへ移動。
5. 会議終了後は両入力停止、資料2件と回答を保持。
6. 文字拡大、約720×560ptへの縮小後もスクロール・資料の展開・取り外し・検索・引用閲覧を操作。
7. 取り外し確認に残存する引用の説明を表示。取り外し後は資料数2→1、「料金」の検索は一致なし。一方、既存回答から同じ取り込み版の引用を開ける。

最初の検証コピーは再署名時に本体のentitlementsを引き継いでおらず、ファイル選択のOpenが無効になった。本体と同じentitlementsで再署名しLaunchServices経由で起動すると、Text選択・取り込みが成功した。製品コードのファイル型制限を緩める変更は行っていない。

画面の確認はCUAのAX状態とスクリーンショットで実施。永続スクリーンショット成果物は作成していない。資料引用付き候補のMarkdown内容は自動テストで確認しており、今回の手動UIでは発話・候補のない資料質問を使用したため、Markdown保存操作は再実施していない。
