## 実装した範囲

- Markdown/Textの1文書保存、取り込み済みリポジトリの一括保存。選択された本文と出典をMac内の専用JSONへ保持。
- 資料ライブラリの一覧・日英の保存名検索・本文と出典の閲覧・明示更新・削除。
- Meeting準備画面から保存版を追加し、既存の全文検索・手動質問・自動提案・終了後要約へ接続。
- 保存時の本文・出典を会議へコピー。ライブラリ更新/削除、会議側の取り外し、Sessionsの引用を独立させた。
- 追加時は手動・自動提案の資料許可を解除。許可・APIキー・絶対パス・音声を保存モデルに含めない。
- 原子的な保存、改訂IDによる古い保存の拒否、破損/未知版の個別エラー、容量制限、リンク/不正パス拒否を追加。

1. `KnowledgeLibraryPersistenceTests`を先に追加。`KnowledgeArchive`未実装によるコンパイル失敗を確認した後、保存・復元を実装し7テスト成功。

3. 同一内容の再保存と、同じ資料を使う複数会議からの古い上書きについて、実際の期待値失敗を確認。会議が保持する改訂IDで照合し、同一内容では日時・改訂を維持するよう修正。14テスト成功。
4. 原本削除、保存量制限、不正パス、手動/自動/要約の引用連携、100項目・1,000ファイルの性能確認を追加。
5. 最終全体テスト: **444テスト／72 suites成功**。SwiftLint **166ファイル・違反0**。Debug（テストビルド）とReleaseビルド成功。

初回sandbox内のXcode実行ではObservationマクロの起動に失敗した。これはRedの根拠にせず、sandbox外の専用一時ビルド先で意図した未実装エラーを確認した。

## 性能

合成リポジトリ1件（1,000ファイル、1ファイル約2,000文字）と通常文書99件を保存した測定:

- 100項目の一覧読込: **0.0746秒**。
- 保存リポジトリ読込と1,000ファイルの索引復元: **0.8335秒**。
- 測定時のプロセス最大常駐メモリ: **405,946,368 bytes**。全テスト並列実行中のプロセス最大値であり、この機能単独の増分でも製品起動時の常駐量でもない。

上記は最初の全体実行の値。最終実行でも一覧0.0724秒、復元0.8320秒、プロセス最大常駐404,258,816 bytesで成功。時間は環境により変動する。200 MiB上限いっぱいのデータや60分実会議の性能保証とは区別する。

## ネイティブUI（合成・無通信）

専用bundle ID `com.gavrri.conflingo.library-preview` のDebugコピーを使用。`--meeting-preview --meeting-state=library-setup`はfake音声/fake AIと合成資料だけを生成する。保存先はプレビュー専用の一時ディレクトリ。利用者の実資料・キー・保存セッションを対象にしない。

確認した操作:

1. Meeting準備画面に文書保存・リポジトリ保存・ライブラリ選択を表示。保持期間と外部送信の説明を確認。
2. 合成`製品仕様.md`と2ファイルの合成リポジトリを保存。保存名・版をMeetingへ表示し、一覧で2件を確認。
3. ライブラリのリポジトリ詳細を開き、READMEとSwiftコードを切り替えて表示。元の取り込み日時、相対パス、内容ハッシュ、snapshot IDを確認。
4. 小文字`synthetic`で`Synthetic Repository`を検索できることを確認。
5. 会議側のリポジトリを取り外し、ライブラリから同じ保存版を追加。文書数が1→3へ戻り、音声停止・AI送信オフを維持。
6. `reviewStatus`を検索し、Swiftコードの1–2行・元のハッシュ付き引用を開く。Escapeで閉じる。
7. 保存画面の更新先で文書を選び、置換対象の確認文を表示。保存名を更新し、一覧で新しい名前と版を確認。
8. ライブラリの文字拡大ボタンを操作。削除確認でEscape取消した後、再度確認して作成済み合成文書を削除。他のリポジトリ項目が残ることを確認。
9. プレビューを終了し、合成資料を生成しない`--meeting-state=setup`でプロセスを再起動。会議内資料0件からライブラリの保存済みリポジトリを選択し、元の版・出典を持つ2文書を新しい会議へ追加。資料送信はオフを維持。

UI確認後の調整: 再保存画面で保存名を引き継ぎ、ライブラリ選択画面の文字サイズをMeetingと同じ値から受け取るよう整理した。型・回帰は最終テストで確認。最初のCUA接続に長い応答待ちがあったが、後続操作は実行できた。
