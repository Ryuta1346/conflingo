## 小窓の受信中停止：確認済み（AXPress）

認証済みの同一ホスト（CDHash `5c9b006725a3c6d50b85220dbaec7c4ea76c85d9`）、製品のGemini 3.8 Flash / medium / 8192、製品小窓・Coordinator・通信クライアントで確認。音声は合成入力、小窓を先に表示してからテスト専用ローカル信号で合成質問を開始した。質問開始UIの受入ではない。実通信に人工的な遅延は加えていない。

- 部分回答と「生成中・未検証」をCUAで観測し、小窓の製品「AI送信を停止」ボタンをAXPressで操作。
- 実受信2チャンク後に取消。部分回答16文字を「中断」として保持し、「AIオフ・外部送信なし」を表示。
- 最初の部分受信から取消まで48.98ms。ボタン押下の個別時刻は取っていないため、クリックからの応答時間ではない。
- 停止後に追加要求なし。後処理後も要求1件、AI送信許可off、review/idle、部分回答保持を確認。ホストの検証テスト1件成功。
- 座標クリックは無通信リハーサルで `windowNotFoundAtPosition` により失敗。AXPressによるUI経路は確認できたが、物理マウスクリックの時刻証跡とは区別する。

無通信リハーサルでは1件目が操作前に完了、2件目でAXPressによる中断と部分回答284文字の保持を確認した。これは実APIの要求数に含まない。
