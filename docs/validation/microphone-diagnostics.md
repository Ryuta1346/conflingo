# マイク発話欠落の診断

2026-11-11 / `feature/pr8-quality-acceptance`。ユーザー「すすめて」で[計画](../design/microphone-missing-speech-plan.md)を承認。
**計測実装・2回の実音声診断完了。両試行とも日本語4文・英語9文を確認。前回の欠落判定は、画面外の行の確認漏れだったため撤回。**

## 計測

- Debugで`CONFLINGO_AUDIO_DIAGNOSTICS=1`の場合だけ有効。通常起動・Releaseでは無効。
- 固定の列挙値による入力別カウンター、サンプル数、フォーマット・変更数、最初／最後の時刻をメモリ集計。音声・認識本文・秘密情報を集計型に渡さない。
- マイクtap・変換結果・コピー失敗・stream投入結果・analyzer消費を記録。両入力についてOS認識結果→controller受信→正規化→store受理／拒否を区別する。
- 入力停止、最終化／取消、hub配送完了の後でスナップショットを固定。停止後の更新を拒否し、再試行時は別UUIDへリセット。
- 音声スレッドでは短いmutex区間の集計のみ。ファイル書込みは停止・配送完了後。Application Supportの`ConfLingo/Validation/audio-diagnostics/<UUID>.json`へ保存し、Debug確認画面に診断IDを表示する。保存失敗も明示する。
- 既存の認識・停止順序・機器・モデル・言語・確定処理は維持。計測追加による実行時間への影響をゼロとはみなさない。

## 実音声

準備完了・マイク許可を利用者が回答。XCTestホストでは内部音声の権限事前確認が失敗し、設定追加・ホスト再起動後も再現した。3件の停止時スナップショットはすべて`inputs: {}`で、音声入力開始前の失敗である。

通常起動との差を調べるため、検証済みDebugアプリを一時領域へコピーし、別名`ConfLingo Audio Diagnostics`、bundle ID `com.gavrri.conflingo.audio-diagnostics`で署名した。認識コードの`ConfLingo.debug.dylib` SHA-256は元ビルドと一致（`01d6c7d4938d750e200a6bf36f55185498d2df425e0790da276fbaefbc4e8ac2`）。一時コピーのInfo.plistだけに`LSEnvironment`で診断opt-inを設定し、サンドボックス・音声入力entitlementは維持。製品のInfo.plistは変更していない。

通常起動でもマイク許可済み・内部音声未許可となった。診断ID `28559C3B-934F-489C-BBFE-5A7C6937169F`の`inputs: {}`を確認し、診断opt-inの反映と入力未開始を確認した。利用者による権限追加・再起動後、両権限の許可を画面で確認し、試験開始に成功した。XCTest固有の問題とは断定しない。

### 前回判定の訂正

今回もスクロール先頭付近のAX取得ではマイク1文だけが見えたが、末尾へ移動すると4文すべてが表示された。`LazyVStack`を使う字幕一覧では、1回のAX取得を一覧全件とみなせない。

そこで前回の停止済みプロセス（PID 95975、元の検証ビルド）を読み取り確認した。入力開始・字幕消去・再実行を行わず、同じ一覧を末尾へスクロールすると、41.2秒の1文に加え、44.1秒の確定行に残り3文と200/100ミリ秒が存在した。日本語4文は2つの確定行に分割されており、英語9行を含め計11確定行だった。

したがって、前回の「後半3文欠落」は実装の不具合を示す証拠ではなく、エージェントの確認漏れだった。該当判定を撤回し、元の受入記録を訂正した。今回の認識処理への根本修正は不要と判断。計測追加は承認済み診断として残し、追加の感度変更・認識モデル変更は行っていない。

### 今後の受入手順

- 取得できたAX本文を全件とみなさず、先頭から末尾まで入力元・時刻を対応付けて確認する。
- 文数と確定行数を区別する。複数文が1行にまとまることを欠落とみなさない。
- 診断を有効にした場合は、試行IDとOS final・controller受信・store受理を照合する。
- 短時間2入力の確認を通常Meeting、会議アプリ別、60分耐久、Gate全体の合格へ代用しない。

## 制限

フレームが継続していても、その中に対象発話が明瞭に含まれていたかは件数だけでは証明できない。OS結果まで届かない場合も、機器・音声内容・OS認識のどれかを追加証拠なしで断定しない。今回は旧試行そのものを再確認して欠落判定を撤回した。一般的な認識欠落が起きないことの証明ではなく、観測した固定素材・短時間の範囲に限る。
