# Sessions 根拠表示のレビュー修正

2026-11-12 / feature/session-persistence

状態: 修正・関連テスト・lint完了。画面表示の自動検証は未完了。レビューで提示した「発話参照と資料引用の両方が空の場合だけ根拠なしと表示する」修正について、ユーザー「修正進めて」で承認。

## 要件と受入条件

保存詳細のAIカードで、資料だけを引用する回答にも「根拠なし・要確認」が表示される。発話参照だけを扱うヘルパーから警告の判定をカードへ移し、発話参照と資料引用の両方が空のときだけ警告を表示する。

- 資料引用のみ、発話参照のみ、両方あり: 「根拠なし・要確認」を表示しない。
- どちらもなし: 「根拠なし・要確認」を表示する。
- 引用への導線と無効な根拠の警告は維持する。

## 実装と検証

1. 保存詳細をNSHostingViewで描画して表示回帰テストを試みたが、この環境ではSwiftUIの警告文・引用ボタンをアクセシビリティツリーから取得できず、検証前提を満たせなかった。製品の不具合によるRedとは扱わず、試行テストは削除する。小さな表示条件の修正のため、テスト用の製品抽象化・依存ライブラリは追加しない。
2. SavedSessionViewの判定だけを最小修正する。
3. 既存のSessions・資料引用関連テストとSwiftLintを実行し、表示条件の4ケースをコードで確認する。ネイティブ画面の表示検証は未完了と明記する。

保存形式・候補の確認条件・Markdown形式の変更は対象外。ユーザー「コミットandプッシュ」により、本修正のコミット・pushが承認された。

SavedSessionViewで警告の判定をカードへ移し、発話参照と資料引用の両方が空の場合だけ表示するよう修正した。既存のライブ画面と同じ条件。資料のみ・発話のみ・両方あり・どちらもなしの4ケースをコードで確認した。
