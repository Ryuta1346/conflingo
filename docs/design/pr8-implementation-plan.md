3. 会議ごとの資料送信許可。初期オフ。既存の発話・質問送信許可と両方が有効な場合だけ資料を手動質問へ付加する。

## 振る舞いの契約

### 取り込み・保持

- UTF-8（BOM許容）の`.md`／`.txt`を対象とする。空本文、無効な文字コード、未対応形式、読み込み不可は成功扱いしない。
- 初期上限: 20文書、1ファイル1 MiBかつ抽出後100,000文字、合計500,000文字。超過時は切り捨てず拒否し、既存資料を保持する。
- 文書ID、タイトル、取り込み日時と不変の本文スナップショットを作る。同名で別内容の資料を勝手に上書きしない。同じ本文の再取り込みは重複として通知する。
- 元ファイルは変更しない。元パスをAPI・ログへ出さない。取り込み後に元ファイルが移動・変更されても、引用は取り込んだ版を開く。
- 本文と索引は会議内のメモリ保持（SQLiteはインメモリを第一案）。Reviewでは保持し、会議破棄／新規会議／アプリ終了で破棄する。保存済みと表示しない。
- Preparationで追加・取り外し可能。Live/Reviewは検索・閲覧・取り外しを提供する。取り外し後は検索／送信対象から除外する。
- 既に生成済みの回答が持つ引用スナップショットは会議破棄まで残ることを取り外し操作で説明する。元資料を削除する操作とは区別する。

### ローカル検索

- 段落・行を基準に最大1,200文字のチャンクへ分割し、長い行も欠落なく扱う。引用位置は元本文の行番号・文字範囲に対応させる。
- SQLite FTS5を使用する。日本語の無空白文で登録語を検索できることを最初の技術検証とする。標準の単語分割だけで日本語を検索できるとは仮定しない。
- トークナイズ方式・OS同梱SQLiteの機能は、合成の日英fixtureで比較して確定する。必要なら日本語用検索語を別に生成し、引用位置は必ず原文へ戻す。検索のための外部APIは使わない。
- ユーザー入力をFTS構文として直接実行しない。SQLパラメータ化と検索語の正規化／引用を行い、記号・引用符・空文字でもクラッシュさせない。
- 最大10件の検索結果を文書名・位置・本文付きで表示。該当なし／検索失敗／資料なしを区別する。部分一致・短語の仕様は検証結果とともに明記する。
- UIや音声処理を塞がないようDB操作を直列化したバックグラウンド処理に置く。会議変更後に旧検索結果を適用しない。

### 資料送信・AI回答

- 手動質問文からローカル検索し、上位最大5チャンク／合計6,000文字を要求のスナップショットとして固定する。発話の既存上限とは別枠とし、HTTP全体のサイズ上限も維持する。
- 許可UIで送信対象（取り込んだ資料の検索に一致した抜粋）・最大量・Gemini送信を説明する。資料送信がオフでもローカル検索は利用できる。
- 資料引用ID、表示用タイトル、位置、抜粋だけを付加する。原本ファイル・全本文・ローカルパスは送らない。ファイル名由来のタイトルも送信対象に含まれると説明する。
- 会議の資料許可と発話送信許可の両方が必要。AI停止、キー変更、資料許可解除で資料を含む要求を取り消し、遅延応答を拒否する。一時停止・会議終了では新規送信を止める。
- 資料取り外しでも該当資料を含む処理中の検索／要求を無効化する。会議破棄で資料許可をオフに戻す。取消で送信済みデータを回収できるとは表示しない。
- 資料内の命令文は引用データとして扱う。発話と資料の矛盾を勝手に解決せず、文書の記述を会議の決定・合意として扱わない。
- 応答の資料IDは今回送信した引用集合と照合する。未知ID・他要求ID・不正形式を根拠として表示せず、未検証状態または応答失敗とする。
- 一般回答は資料だけでも根拠を表示できる。決定／アクション候補の確認には、引き続き有効な発話根拠を要求する。資料引用だけで確認可能にしない。
- 引用IDの形式的な一致と回答の意味的な正しさは別に検証する。fake成功だけで実モデルのRAG品質を合格にしない。

### UIと出力

- Preparationに資料の追加・一覧・保持期間を配置。Liveの手動質問に資料参照状態、検索結果と引用閲覧を接続する。
- 引用を開くと取り込んだ版の文書名・取り込み日時・位置・該当箇所を表示する。元アプリの起動は必須にしない。
- 「資料なし」「資料送信オフ」「一致なし」「資料を参照」「無効な根拠」を区別する。架空の引用は作らない。
- PR7の候補出力に資料引用がある場合、タイトル・位置・抜粋・取り込み日時をMarkdownへ含める。未確認／却下の区別とエスケープを維持する。
- 狭幅・文字拡大・キーボード操作で追加→検索→引用閲覧→取り外しを操作できる。Floatingからは主画面の該当引用を開ける導線を提供する。
