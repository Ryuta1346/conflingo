## 更新版の具体案

- Gemini / OpenAI / Claudeは各社公式APIへ接続する。
- Kimi / DeepSeekは設定プリセットを用意する。その他クラウドはOpenAI互換APIのBase URL・APIキー・モデルを設定する。複数接続の保存と切替に対応する。
- ローカルはPCに導入したQwen等を使用する。提案方式は同じMacで起動済みのOllama / LM Studio等のOpenAI互換APIへの接続。Qwenがモデル名であることと、実行ソフトの選択を区別する。APIキーは接続先に応じて任意。
- モデル一覧取得とモデルID手入力、接続確認、出力方式の設定を用意する。
- 選択をMeetingの質問・自動提案・資料参照・要約へ共通適用。文字起こし・翻訳は現在のApple処理を継続する。
- ローカル推論エンジンの内蔵・モデルの自動ダウンロード・LAN内の別PCへのHTTP接続・独自認証APIは初回範囲外。
