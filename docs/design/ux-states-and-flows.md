# ConfLingo — フロー・状態・受入仕様 v0.1

2026-11-08 / PR5-A モックの方向性承認済み。以下の個別受入項目はユーザーによる実施・合格を記録するものではなく、未検証を維持。モック上部のレビュー操作は製品UIの外側。画面切替は任意状態へのジャンプ、画面内の開始/停止は連続フローの試作。

## 主要フロー

1. **Conference:** Home→準備（言語、文字起こしのみ、高速確定、辞書）→開始→字幕→停止→再開またはMarkdown書き出し。Clearは停止後に確認して消去。辞書編集は準備へ戻る。
2. **Meeting:** Home→会議名・入力別言語→参加者への通知/同意確認→クラウドAIの任意許可→開始→Live。音声は保存/送信せず、AI許可時のみ必要な確定発話等を送る設計。通知チェックは相手の同意取得そのものを代行しない。
3. **提案と根拠:** 提案→発話時刻→引用→戻る。決定/アクションは「候補」から明示的に確認/却下。生成だけで確定しない。
4. **中断:** 収集を一時停止→新しい収集/AI送信を停止→再開。クラウドAI停止は音声収集を止めない。会議終了は両方停止し、残ったfinal処理完了後Reviewへ。停止失敗ならReviewへ遷移しない。
5. **振り返り:** Reviewで候補確認→Markdown書き出し、または明示的ローカル保存。保存しない場合は確認して破棄。書き出しとアプリ内保存は別操作。
6. **Sessions:** 明示保存された会議だけを検索/閲覧/削除。削除は確認後実施。書き出した外部Markdownは連動削除しない。
7. **Floating:** Live→コンパクト→展開復帰。非表示は収集停止ではない。復帰はアプリのウィンドウメニュー等から。モックはOS操作を代替する「再表示」ボタンを外側に置く。

## 状態表

| 状態（モック表記） | 表示 | 許可する操作・復帰 | 主な対象 |
|---|---|---|---|
| idle / 空 | 入力停止、未保存、開始案内 | 設定、開始 | 全画面 |
| requestingPermission / 権限確認 | 要求する入力と目的 | キャンセル。許可後は準備へ | 準備 |
| preparing / 準備中 | 言語モデル準備、進捗不明は割合なし | キャンセル。完了→開始可能 | 準備/字幕 |
| listening / 通常 | 入力別に取得中、AIは許可と送信を別表示 | Pause/Stop、Ask AI、根拠、表示変更 | Live |
| paused / 一時停止 | 両入力停止、新規AI送信なし | 再開、終了、保持済み発話を読む | Live |
| stopping / 停止中 | 終了処理中 | 二重操作不可、失敗時に再試行へ | Live |
| error / 入力切断 | 両入力停止、発話保持 | 準備へ戻り入力を確認、再開 | Live |
| permission-denied / 権限拒否 | 利用できない入力と設定場所 | 設定手順を表示、再確認 | 準備/Live |
| stop-failed / 停止失敗 | 停止未完了、入力状態は要確認 | 停止再試行。新規開始/Clear不可 | Live |
| sending / AI送信中 | 確定発話を送信、回答生成中 | AI停止、音声収集継続 | Live/Floating |
| offline / オフライン | AI停止、ローカル字幕継続 | 再接続、AIを使わず継続 | Live |
| reconnecting / 再接続中 | AI接続確認、字幕継続 | AI停止、終了 | Live |
| AI-disabled / AIオフ | 外部送信なし、字幕継続 | 送信対象を確認して許可 | Live |
| no-knowledge / 資料なし | 発話のみ参照、資料根拠なし | 発話の根拠を開く | Live |
| no-insights / 提案なし | 提案待ち、音声収集は継続 | Ask AI | Live |
| translation-failed / 翻訳失敗 | 原文は継続、対象訳文に失敗表示 | 原文確認、停止後設定確認 | Conference |
| saved / 保存済み | 保存先と結果 | Sessionsで閲覧、書き出し | Review |

入力切断時に片方だけ継続する設計にはしない。PR4は片系失敗で両系統を停止する。AIネットワーク障害は音声とは独立して縮退する。

## モックの再現範囲

上部「画面」「状態」「配色」「文字」で閲覧。主要フローは画面内ボタンで実行できる。データは架空、リロードで初期化。ダウンロードはレビュー用のサンプルMarkdownのみ。権限要求、音声取得、外部AI送信、ファイル取り込み、OS最前面制御、Keychain、実セッション永続化はシミュレーション。

保存済みセッションと資料参照の画面は後続PR向け設計。製品コードが対応済みという意味ではない。共有画面への映り込みは未検証。
