# ConfLingo — デザインシステム案 v0.1

2026-11-08 / モックの方向性承認済み。個別のネイティブ実装・受入は後続。HTMLはSwiftUI移植の視覚・操作リファレンスでありWeb技術の製品採用ではない。

## 方向

白に近いグレー、低彩度のサイドバー、青を主要操作と選択に限定する。会議中は文字が主役。余白・文字の太さ・細い区切りで情報の優先順位を作る。写真、装飾グラフ、常時点滅、強制フォーカス移動は使わない。

SwiftUIでは動的Colorと環境設定へ対応させる。半透明素材はナビ/フローティングの構造領域に限定し、本文は不透明面で読む。コントラスト増加・透明度低減はネイティブ実装で別途検証する。

## 文字・寸法

- システムフォント。macOSではSF、日本語はシステムフォールバック。本文14px/1.7、補助12px/1.5、画面タイトル24px/1.3、主提案22px/1.6、字幕は初期18px/1.8。製品字幕は既存fontSize設定16pt等を引き継ぎ、無断リセットしない。
- 数値・時刻は等幅数字。全文の大文字や文字間の広い装飾見出しは使わない。
- 余白4/8/12/16/24/32px。操作の高さ32〜36px、主操作40px。角丸は操作7px、パネル12px、ウィンドウ14px。
- 通常1280×800、14インチの参考1512×982、狭幅720×800。660px以下では単列化。拡大時も本文/ボタンを切り捨てずスクロールできる。
- Floatingは目安440×350、最小320px幅。1提案＋引用元＋収集/送信状態＋操作。位置/寸法の保存は5-C。

## 操作・アクセシビリティ

全操作に可視ラベルまたはアクセシブル名。選択状態はaria-pressed/current相当。TabのDOM順と視覚順を合わせる。フォームは永続ラベル、エラーは対象と関連付ける。バナーはpolite、字幕全文を毎回読み上げない。重要な停止エラーだけ即時通知を検討。

⌘Rと⌘＋/⌘−は既存維持。その他の新規ショートカットはOS/会議アプリとの衝突確認後に確定する。HTMLモックではブラウザの⌘Rを奪わず、ネイティブの実機確認を残す。

動きはhover/選択への短い反応を中心にする。Reduce Motionでは移動効果を省く。提案追加でフォーカスを奪わない。ユーザーが開いたシートのみフォーカスを移す。Floatingは画面共有から隠れる保証をしない。
