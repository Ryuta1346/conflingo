## 手順

1. 同じ新ビルド（CDHash `5c9b006725a3c6d50b85220dbaec7c4ea76c85d9`）に検証専用バンドルを読み込む。既存製品View/小窓/Coordinator/クライアントを使用し、音声のみ合成入力にする。
2. 小窓を先に表示・前面にしてから、検証専用のローカル開始合図で合成質問を送る。小窓には製品の停止ボタンだけを用いる。送信開始の操作経路そのものの受入とは区別する。
3. 無通信fakeクライアントで小窓の取得・座標クリック・中断保持をリハーサルしてから実通信へ進む。実通信は回答や受信を人工的に遅延させない。
4. 実受信の部分回答を画面で観測して、小窓の停止ボタンを操作する。座標クリックはツールが `windowNotFoundAtPosition` で失敗するため、無通信で確認したAXPressによる製品ボタン操作へ切り替える。操作直前の生成中表示、操作後の取消、部分回答保持、停止後の要求増加なしを確認する。`mouseUp` を伴う物理クリックの証拠とは区別する。1回成功で終了。失敗した場合だけ残る1回を使い、2要求で終了。
5. 同じホストの無通信プレビューで言語選択・設定移動・開始/一時停止/再開/終了・小窓展開/非表示のキーボード経路を確認。必要なら一時的なOSキーボード設定変更を記録し終了時に復元する。VoiceOverはOS設定で有効化状態を確認し、フォーカス/読み上げを観測可能な範囲で評価し、元へ戻す。AX取得を実読み上げ合格の代用にしない。

## 費用・データ

Geminiへの合成テキストのみ、既存Keychainキーを同じ認証済みホストで利用。キー変更/削除なし、キーと生成本文は作業ファイルへ保存しない。要求開始前に専用台帳へ予約し、最大2要求。前回確認単価で入力10713・思考込み出力8192 token/件なら2件約US$0.0775。入力予約を要求本文byte数以上とし、予約込み推定US$0.10を超える前に停止する。取消や使用量不明を0円扱いしない。実請求額の保証ではない。

## 残件の境界

60分の実会議耐久試験はPR9/Gate Dの要件で、延期中の実音声を必要とする。無通信の短時間試験で合格に置き換えない。実請求額もGoogle側の請求記録と照合できなければ未確認を維持する。今回の小窓/キーボード/VoiceOver結果と、これらの後続項目を分けて記録する。

## 継続調査

ユーザー「進めて」により無通信でキーボード経路の切り分けを継続。主画面のTab停滞が自動操作で再現したため、[確認票](../validation/pr6-accessibility-hearing.md)に事実と比較項目を整理し、物理キー操作の結果を依頼中。回答待ちの間は対象画面を変更しない。追加API送信なし。

### 同名プロセスの切り分け

利用者は実キーで「何も動いていないように見える」と回答。通常のシステム設定では自動Tab移動が成立する一方、ConfLingoは3プロセスが同じbundle IDで起動中。元ホストを保持し、同じビルドを一時ディレクトリへコピーして検証専用bundle IDへ変更・ローカル署名する。これは無通信プレビュー専用で、Keychain/APIにはアクセスしない。製品ソースや配布設定の変更ではない。識別子を分けてTab経路を再検証し、結果を元ビルドの証跡と区別する。

### 切り分け結果

[検証コピーの主要キーボード経路](../validation/pr6-keyboard-isolation.md)を確認。回答言語・OS設定を復元し、合成会議を終了した。元ホストの署名・67ソースハッシュ、製品dylib一致を確認。VoiceOverと一時的なフォーカス停滞の原因は未確定。利用者の実キー回答は受領済み、追加API送信なし。

### フォーカス反復とVoiceOver起動の再評価

[反復確認](../validation/pr6-focus-stability.md)でフォーカス45回・往復3回成功。製品修正の根拠なし。VoiceOver本体と出力プロセスの起動は確認したが実読み上げは未観測、利用者の聞こえ方/キャプションの回答待ち。VoiceOverは元のoffへ復元し、追加API0件。

### 利用者確認による基本受入の記録

ユーザー「聞こえた、見えた」「設定画面が開いた」を受領。VoiceOverの実読み上げ・キャプション・設定ボタンの実キー操作を利用者確認として記録し、依頼を終了。ツールによる画面遷移の独立追認は得られず、制約を[結果](../validation/pr6-focus-stability.md)に明記。VoiceOver offへ復元。今回の非録音UI主要確認と、実音声・全画面網羅等の残件を区別する。
