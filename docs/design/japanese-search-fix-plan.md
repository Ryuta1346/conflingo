## 再現と調査結果

本文`料金は月額100円です。`を取り込んでも、短い検索語`月額`で一致しない。既存処理は原文と識別子展開後の文を、同じ文であっても連結してからNLTokenizerへ渡す。本文のトークンは`月額`、検索語のトークンは`月`・`額`となる。

独立した診断で、日本語指定だけでは連結済みの`月額 月額`を修復できないこと、重複を避けて日本語を指定すると`月額`を1語にできることを確認。元本文・引用・保存形式には問題がない。

## 変更範囲

- `KnowledgeIndex.words`: 識別子の展開前後が同じ場合は同一文を重複させない。空白で区切った語句を本文・検索語・復元時に同じ方法で正規化する。レビュー後は通常の言語判定を優先し、複数の1文字漢字だけへ分裂する語句に限定して日本語の分割規則で補う（末尾の追加修正参照）。前後の空白、語の繰り返し、英語との併記でも短い語が分裂しないことを診断済み。英字大小・全半角・アクセント、camelCase/snake_case展開は維持する。
- 公開検索APIを通じた回帰テストを追加し、短い検索語の単体利用と無関係な1文字の誤一致を検証する。
- 資料ライブラリの保存→新規索引への復元と、リポジトリ内の日本語資料でも検索できることを確認する。
- FTSのOR検索、順位付け式（BM25とパス重み）、検索件数上限、引用位置、AI送信許可、保存形式は変更しない。部分文字列検索や新しい検索APIは追加しない。
