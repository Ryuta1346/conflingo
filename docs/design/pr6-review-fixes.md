# PR6 レビュー指摘2件の修正計画

2026-11-09 / feature/insight-engine / 基点 6f31555

ユーザーの「修正進めて」により、レビューで提示した2件の修正を承認済み。以下の実装と自動検証を完了。独立レビューで両指摘の解消を確認し、追加の不具合指摘なし。[検証記録](../validation/pr6-insights.md)参照。

1. AI購読の接続から両入力の開始成功までに届く対象確定発話を、最大30件・合計12,000文字で一時保持する。巨大な単一発話は保持しない。開始成功時に新しい対象発話を優先し、既存の同時要求・頻度制限を適用する。開始失敗、停止、許可取消、自動提案オフで保持内容を破棄し、再開時に古い待機要求を送らない。
2. AI購読の障害状態を通信エラーと分けて保持する。購読障害中は自動提案を再有効化できないようにし、主画面に「一時停止→再開」の復旧案内を表示する。手動Ask AIと字幕は継続できる。新しい購読の接続後に切替を再び許可し、自動提案はユーザーが明示的にオンにする。
3. 再現テストを先行し、意図した失敗を確認してから最小実装する。起動待ち、開始失敗、取消、バッファ上限、実AI購読のoverflow、許可の再切替・手動質問後にも復旧案内を維持すること、再接続後の新規発話処理を検証する。
4. 関連テスト、全ローカルテスト（実Gemini評価を除外）、SwiftLint strict、差分確認を行い、利用ガイド・検証記録・進捗を実装結果に合わせる。

API・音声の実接続は含めない。修正完了後、ユーザー「コミットandプッシュ」によりコミット・pushを追加承認。会議や字幕の永続化・互換性に変更はない。

保存先: `~/.coding-agents/docs/conflingo/feature-insight-engine/001_pr6-review-fixes.md`

結果: 追加テストで起動中の取りこぼし・購読障害後の誤ったオン表示を再現し、修正後は関連17テストと全267テストが成功。SwiftLintは101ファイル・違反0。巨大な単一発話の除外はテスト済み。バッファの合計文字数・件数上限と新しい発話優先はコードレビューで確認し、それぞれの境界を直接検証する専用テストは未追加。
