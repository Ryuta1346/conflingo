## 修正内容

ライブラリから追加する一覧で、追加済みの資料のアクセシビリティ名を「資料名、選択済み」にする。未選択の資料は「資料名を追加」を維持する。表示文字・追加済みの無効化・閲覧操作・保存形式・外部送信の条件は変更しない。

## 実施順と受入条件

1. 関連する設計資料に、資料名と選択済み状態をアクセシビリティ情報に含める仕様を反映する。
2. `DR5InteractionTests.libraryOpenAreaAndSelectionKeepIndependentActions`で選択状態がアクセシビリティ名に含まれることを検証し、現行実装で失敗することを確認する。未選択の追加操作、選択済みの無効化・コールバック未実行・詳細閲覧も維持する。
3. `KnowledgeLibraryView`のラベルを選択状態で切り替える最小修正を行う。
4. 関連テスト、ローカルのLint・全非liveテスト・両CPU Release、差分検査を実行する。GitHub Actionsは実行しない。
5. 検証用プレビューで資料追加後に一覧を再表示し、「選択済み」の表示とアクセシビリティ名・無効状態を確認する。VoiceOverの実読み上げはユーザー指示による保留を維持する。
6. 結果と残る受入を検証記録・plan.mdへ反映する。

当初の実装承認にはコミット・push・PR投稿を含めなかった。検証完了後、ユーザー「コミットand PR反映」で追加承認済み。ユーザー提供AGENTS.mdの実装前承認も取得済み。
