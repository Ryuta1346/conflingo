## 着手時点の現状と課題

- `DesignTokens.swift`は色・パネル角丸12・余白24のみを定義。文字とボタンの共通様式がない。
- 現行の`.font(.caption…)`／`.font(.caption2…)`は35ファイル・161箇所。送信対象・件数・送信先など判断に必要な説明にも使われる。
- `AppShellView`のaccent指定を通常ボタンも継承する。削除・字幕消去・停止再試行・根拠リンクの見た目が画面ごとに違う。
- `SessionErrorBanner`、警告色のText、色なしのTextが混在。`MeetingExportState`・`KnowledgeStore`・`APIKeyCredentials`等は成功と失敗を同じ文字列プロパティへ設定している。
- 翻訳準備、履歴・資料の読み書きでは、日本語の案内に`localizedDescription`を連結している。文字列の内容だけから表示種別や詳細部分を判定する設計は避ける。
- DR2はローカル履歴でPR #47のマージを確認。DR2の幅条件・提案優先・上部保存・フォーカス復元を回帰条件とする。

現行画面は既存の`WorkspaceRegionLayoutTests.captureApprovedWidths`で無通信の合成描画を取得する。結果は[事前確認記録](../validation/dr3-baseline-2026-11-15.md)へ記録する。送信説明・失敗・シート内部の追加描画と操作確認は実装時の受入に含める。

## 1. 文字様式（D04・D15）

ネイティブの単位をptで定義する。システムフォントを使い、用途別に名前を付ける。

| 用途 | サイズ・太さ | 適用先 |
|---|---|---|
| 画面タイトル | 24pt・semibold | PageHeading等 |
| セクション見出し | 17pt・semibold | 設定・一覧・カードの見出し |
| 操作／本文説明 | 14pt・regular（主操作はmedium） | ボタン、フォーム説明、送信範囲 |
| 補助 | 12pt・regular | 入力元、時刻、状態、短い案内 |
| 注記 | 12pt・regular | 出典情報、補足。補助より小さくしない |

- 製品画面のcaption／caption2と用途が同じ固定サイズを共通様式へ置換する。注記の階層はサイズ縮小ではなく色・配置で表す。
- 「何を・何件・どこへ送るか」、料金・保持条件、許可の適用範囲は14pt・本文色。Meeting／Conference、資料質問、Web調査、要約確認、LLM設定を確認する。説明文を省略したり、初期の開閉状態を変更したりしない。
- 字幕・提案・保存本文の`fontSize`は引き継ぐ。全読書領域への設定適用拡張はDR4（D13）。
- 数値・時刻の等幅、選択可能な本文、見出しのアクセシビリティ属性を保持する。

## 2. ボタン4様式（D06・D15）

共通ButtonStyleを定義し、既存のButtonへ適用する。アクション・disabled・キーボード操作・アクセシブル名を部品に移して隠さない。

| 様式 | 見た目 | 主な適用例 |
|---|---|---|
| 主要 | accent面＋配色に応じた文字色 | 開始、質問送信、確定保存、シートの確定操作 |
| 通常 | surface面・本文色・細い境界 | 一時停止、再試行、書き出す、設定、閉じる |
| 破壊 | dangerの文字・境界、roleもdestructive | 会議終了、字幕消去、履歴・資料・接続・キーの削除 |
| リンク | 枠なし、accent文字、フォーカス可視 | 発話・資料の根拠へ移動、詳細を見る |

- 主要操作は同じ操作群で1つを原則とする。Meeting／Conferenceの「停止を再試行」は通常様式に揃え、失敗は隣接メッセージで示す。
- 角丸7pt、横余白12pt、通常の高さ32pt以上、開始等の主操作40ptを目安とする。コンパクトな根拠リンクは本文の行高に従う。狭幅で複数行や折り返しを許容する。
- 選択済みナビ、Picker、Toggle、メニュー項目、システムの確認ダイアログはOSの操作契約を保つ。ナビ選択の青を通常ボタン化で消さない。
- ライト／ダークでenabled・disabled・押下・キーボードフォーカスを確認。新しい主要様式のダーク文字は本文色との組み合わせを実測し、4.5:1以上を受入条件にする。D21全体の完了とは扱わない。
- 既存の削除・終了確認、キャンセル、二重操作防止を維持する。

## 3. 行内メッセージ（D07）

小さい共通の表示モデル（種別・日本語本文・任意の詳細）と`InlineMessage`を設ける。

| 種別 | 記号 | 色 | 例 |
|---|---|---|---|
| 情報 | info.circle | secondary | 処理中、取消、未保存 |
| 成功 | checkmark.circle | positive | 保存・書き出し・取込完了 |
| 警告 | exclamationmark.triangle | warning | 保存後に変更、未確認、要対応 |
| 失敗 | xmark.octagon | danger | 保存・読込・翻訳準備・接続の失敗 |

- 記号＋文章を常に併記。日本語本文には影響と次の操作を含める。再試行ボタンは呼出元が配置し、既存処理へ接続する。
- システム由来の文言は初期状態で閉じた「詳細」に表示し、全文選択・コピー可能にする。日本語の復帰案内は折り畳まない。秘密情報を除去している既存のエラー処理を維持する。
- 成否を文面の部分一致で推定しない。既存の状態があればそれを使い、不足する状態所有元だけに表示種別と詳細を追加する。永続形式は変更しない。
- 保存・書き出し、資料取込／検索／用語抽出、LLM接続／キー、AI支援／Web調査、翻訳準備／再試行、入力停止失敗へ適用する。取消を失敗と表示しない。
- `SessionErrorBanner`を同じ表示部品へ移行し、使用されなくなった旧表示は削除する。字幕の認識中ラベル・候補バッジ等の継続的な状態表示は独立した役割として維持する。
- 「詳細」を閉じても入力・回答・エラー状態を失わず、失敗から復帰したときに古い失敗詳細を残さない。

## 4. トークンとシートの整理（D15・D16）

- 操作角丸7、パネル角丸12、余白4/8/12/16/24/32を共通定義する。変更部品とシートから利用し、StatusLabelやエラーパネルの逸脱も整理する。
- アプリ所有の情報・閲覧シートは右上に「閉じる」、編集フォームは下部右に「キャンセル」「確定」の順で統一する。Escapeと閉じた後のフォーカス復元を維持する。
- アプリ所有シートはcanvas背景・内容余白24を基本にする。共通するLLM設定の外枠を揃え、通常幅680pt・狭い表示では利用幅内に収め、縦はスクロールする。
- シートの内容・重なり順・機能分割は変えない。システムの保存／ファイル選択／確認ダイアログは対象外。
- DR2で確定したサイドバー幅・レイアウト境界、小窓寸法をトークン整理に合わせて変更しない。D15の未変更項目は結果に明記する。

## 変更箇所と実施順

1. 承認内容を本書と`design-system.md`・`ux-states-and-flows.md`へ反映し、旧記載との優先関係を明示する。
2. `DesignSystem/`に文字・ボタン・行内メッセージの最小部品を定義する。振る舞いのテストを先に書き、意図した失敗を確認して実装する。
3. `Meeting/Views/`・`Conference/Views/`・共通Views・Sessions・KnowledgeLibrary・Appシェル／設定／小窓の順に置換。関連する状態所有元は表示に必要な変更に限定する。
4. 保存・資料・LLM・翻訳などの失敗／復帰、シート・根拠リンク・ボタンの操作回帰をTDDで確認する。
5. 全非liveテスト、Lint、両CPU Release、ネイティブ描画・キーボード操作を確認。不要になった部品・表示分岐・重複資料を整理する。
6. `plan.md`へ結果と未確認事項を反映する。マージ・受入前はDONEにしない。

## 受入条件・検証

- 単なる定数の一致だけでなく、実ビューをホストして表示・操作を検証する。ソースの旧指定検索は置換漏れ確認の補助に使う。
- 文字: 送信範囲の全文が本文色・14ptで読み取れる。補助・注記は12pt以上。長いURL、日本語長文で欠けない。
- ボタン: disabledで実行しない、enabledで1回実行する、Tabから操作できる。根拠リンクが元の発話へ移動する。削除・終了は確認前にデータを変えず、取消後に戻れる。
- メッセージ: 成功／失敗／取消／処理中を取り違えない。失敗本文は日本語、詳細は初期非表示で開閉・全文参照可能。失敗→再試行→成功で表示が更新される。
- 状態所有元: fakeの保存失敗・取込失敗・Keychain失敗・翻訳準備失敗で表示種別と復帰を検証する。既存保存・AI許可・取消・世代判定のテストを維持する。
- シート: Meeting／ConferenceのLLM設定、接続編集、資料・引用の閉じる位置・背景・余白を照合する。Escape・キャンセル・起点フォーカスを確認する。
- 640／900／1280／1512pt、ライト／ダーク、本文16／32／48ptの代表画面を確認する。640×520でも操作へスクロールで到達でき、説明・メッセージが切れない。5幅のDR2描画回帰も実行する。
- `bash scripts/ci.sh lint`、`bash scripts/ci.sh test`、`bash scripts/ci.sh release`、`git diff --check`。必要なUIテストでは既存のキーボードナビゲーション前提に従う。
- 実音声・実APIは使わず、fake状態と一時保存先で検証する。VoiceOver実操作は既存のユーザー指示どおり保留。独立レビューの実施有無は明記する。
