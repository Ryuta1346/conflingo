# PR6 非録音・実API UI受入の実装計画

2026-11-09作成・2026-11-10更新 / base main `d0b4379` / 状態: 承認済み実装・自動検証・今回の受入検証を実施。品質と通信中停止に未解決事項あり、REVIEW継続

## 目的と前提

PR6の受入検証を進める指示に基づき調査した結果、通常アプリはMeeting開始に実音声を使用し、既存プレビューはAIとKeychainもfake固定だった。実音声試験の延期を守ったまま、製品のMeeting UI、Keychain、Gemini、停止連動を結合検証するため、Debug限定の最小経路を追加する。

これは合成入力でのアプリ結合受入であり、実音声を含む通常起動全体の受入とは区別する。ユーザーの実会話は外部送信しない。

## 変更範囲

1. `MeetingPreview.swift`: 合成音声・合成発話の既存fixtureを再利用し、明示した実API検証モードだけ本番Gemini/Keychainへ接続する。既存のモックモードはそのまま。架空の回答を実生成と混同しないよう、実APIモードでは架空カードを投入しない。
2. `ConfLingoApp.swift`: DEBUG内で既存の`--meeting-preview`に加えた明示フラグ`--meeting-live-ai`を解釈する。単独フラグでは実API検証を有効化しない。通常起動・Releaseの構成を変えない。
3. Meeting画面: 実API検証モードでは「合成発話・音声取得なし・Geminiへ実通信」を表示する。API料金発生と送信内容は既存の許可UIで確認できる。自動提案と送信許可は初期オフ、起動だけでは送信しない。
4. 構成選択・初期状態・架空カード混入防止をテストする。キーは既存の本番Keychainだけを利用し、dotenv読込やキー自動登録は製品へ追加しない。既存キーを置換・削除する受入は行わない。

## 実装順序

### 受入中に再現したKeychain停止への対処

実APIモードのAsk AIでも、既存キーの読み出しがメインスレッドをブロックした。受入を継続するため、読み出しをバックグラウンドへ移し、読出し待ちの取消後にHTTP送信しないことを追加テストする。既存項目はfile-based Keychainであり、LAContextとクエリのUI禁止だけでは別ビルドからの待機を抑止できなかった。一時プロセスではlegacy KeychainのUIを禁止すると即座に認証失敗となったため、読み出し時だけ非対話化し、以前の設定へ必ず戻す。保存先移行、既存キーの変更、アクセス権や署名要件の変更は行わない。読み出し失敗を「未登録」と混同しない。

根拠: [Apple SecItemCopyMatching](https://developer.apple.com/documentation/security/secitemcopymatching(_:_:))はメインスレッドでのブロックを警告。現行SDK `Security.framework/Headers/SecItem.h`には、legacy Keychainでは一部のクエリUI禁止属性でもUIが起動し得る旨の記載がある。

- 承認後、関連設計資料と受入条件を先に更新する。
- tddスキルを適用し、構成と初期状態の振る舞いをテストで先に失敗させる。
- 最小実装を行い、テスト成功後に不要コードと資料の整合を確認する。
- 全Swiftテスト、Debug/Releaseビルド、SwiftLintを実行する。Releaseに実API検証起動経路が入らないことも確認する。

## レビュー後の登録状態競合修正（2026-11-10・実装・自動検証済み）

ユーザー「修正進めて」により承認。登録確認中に保存が失敗すると、進行中の確認結果が破棄され、既存キーが未登録と誤表示される問題を修正する。保存・削除成功時だけ古い確認を無効化し、失敗時は確認を継続する。確認完了は待機中に発生した保存・削除エラーを消さない。過去のメッセージは新しい確認開始時に消去する。

回帰条件は、保存失敗後のキー有無の正しい反映、削除失敗後の登録状態保持、失敗メッセージ保持、保存・削除成功後の古い結果による上書き防止。遅延可能な合成ストアで検証し、実API評価は今回の対象外。

追加テストで保存・削除失敗時の確認中表示と既存キー反映の失敗（5 issues）を確認後、最小修正を実施。全283テスト／41 suites成功（`GeminiLiveEvaluationTests`除外）、SwiftLint 104ファイル・違反0、差分の空白チェック成功。ログは`/private/tmp/conflingo-credentials-fix-{red,tests,lint}.log`。既存の非推奨Keychain API警告は残存。今回の検証はDebugテストと合成ストアの回帰確認であり、Release・実API・実音声・UI受入は再実施していない。
