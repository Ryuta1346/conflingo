## 手順・受入条件

1. 利用者の読み上げ準備、同じBoseの入力・出力、両入力・素材の停止を確認する。
2. 専用確認画面で短く再開し「再開後の確認です。次の確認は木曜日です。」を入力。停止後、旧字幕を保持したまま新しい確定行が加わり、過去の4文や英語素材の重複・認識中行残存がないことを先頭から末尾のAXと試行別数値で確認する。英語素材は再生しない。
3. 専用確認画面を閉じて停止を維持し、主画面の通常Meetingへ移る。会議名は架空の受入試験名。マイク日本語・内部音声英語。参加者同意は利用者の準備完了回答を根拠に設定する。Gemini送信許可・自動提案はoffを確認する。
4. 会議を開始し、両入力取得中を確認して英語固定素材23.289秒を1回再生。終了後に「通常の会議画面を確認します。次のレビューは木曜日です。」を読む。英語9文と日本語2文の入力元・内容を確認して一時停止する。
5. 両入力停止・確定字幕保持・再開可能を確認。再開して「再開後の締め切りは金曜日です。」を読む。会議終了後、review画面・両入力停止・追加文の保持・旧字幕の重複なし・認識中行残存なしを確認する。
6. 各停止の数値メタデータだけを保存。前回の確認漏れを繰り返さないため、単一のAX本文を一覧全件とみなさず、スクロール末尾まで文数と確定行数を区別して照合する。

## 境界

今回の実入力区間は専用画面1回、通常Meetingの開始と再開の2区間。失敗時は停止して原因を記録し、無制限に再試行しない。新しい権限が必要なら利用者へ依頼する。Gemini送信・要約生成・本文のMarkdown保存・音声ファイル保存は今回の対象外。既存字幕の消去は行わない。会議アプリ別受入、AI結合、Conference、60分耐久、Gate全体の合格には代用しない。
